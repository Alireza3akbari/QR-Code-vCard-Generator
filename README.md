# QR Code 1

A simple Python tool that creates QR codes containing contact information (vCard format).  
When scanned, the QR code lets users save the contact directly to their phone.

## Features
- Supports name, phone, email, and organization.
- Automatically cleans and formats phone numbers.
- Saves the QR as a PNG file.
- Easy to use with simple terminal input.

## Usage
```bash
python qr_vcard.py
